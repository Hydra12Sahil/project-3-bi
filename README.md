# Super Store Sale and Profit Dashboard

An interactive Power BI dashboard designed to analyze and visualize sales, profits, and operational performance metrics for a Super Store across the years 2019 and 2020. 

## 📊 Project Overview
This project provides a comprehensive overview of the business performance of a retail store. It tracks key performance indicators (KPIs) and provides deep insights into sales trends, profit margins, shipping modes, customer segments, and regional distributions to help data-driven decision-making.
![image](https://github.com/Hydra12Sahil/project-3-bi/blob/master/Screenshot%202026-06-01%20101214.png?raw=true)
## 🔑 Key Metrics (KPIs)
* **Total Profit:** $175K
* **Total Sales:** $2M
* **Total Orders:** 22K
* **Average Delivery Days:** 4 days

## 💡 Key Features & Insights
* **Trend Analysis:** Dual line charts comparing **Sales Month-and-Year** and **Profit Month-and-Year** for the years 2019 and 2020 to track seasonal performance.
* **Customer Segmentation:** A donut chart showing **Sum of Profit by Segment** (Consumer: 46%, Corporate: 33%, Home Office: 21%).
* **Payment Mode Analytics:** Breakdown of profit based on payment types (**COD: 47%**, **Online: 31%**, **Cards: 22%**).
* **Product Performance:** 
  * **Profit by Category:** Technology ($90K), Office Supplies ($75K), and Furniture ($10K).
  * **Top Sub-Categories:** Copiers ($43K), Accessories ($25K), and Phones ($22K).
* **Shipping & Logistics:** Bar chart showcasing **Profit by Ship Mode** (Standard Class leading with $52K, followed by First Class, Second Class, and Same Day).
* **Geographical Insights:** An interactive map visual displaying the **Sum of Profit by State and Sales** across North America.
* **Interactive Slicers:** Region-based buttons (**Central, South, East, West**) to easily filter the entire dashboard data dynamically.

## 🛠️ Tools & Technologies Used
* **Power BI Desktop:** For data transformation, modeling, DAX creation, and visualization.
* **Data Source:** Super Store Sales Dataset (Excel/CSV).

## 🚀 How to View the Project
1. Download the `.pbix` file from this repository.
2. Open it using **Power BI Desktop**.
3. Interact with the slicers (Regions, Years) to explore different insights.
